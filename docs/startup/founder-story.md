# Founder Story — Amrit Kumar

## The Problem That Became Personal

Across India, healthcare documents follow patients everywhere — yet belong to no one in particular.

A lab report from Thyrocare. A prescription from a local clinic. A discharge summary from a hospital visit. An insurance claim document. Each arrives in a different format, from a different provider, with no connection to the last.

Patients stash these in WhatsApp chats, email inboxes, and paper folders. When it is time to visit a new doctor or explain a family member's history, the records are scattered, incomplete, or impossible to interpret.

For Amrit Kumar, this stopped being an abstract problem when a family member needed repeated help understanding blood test results. The reports were full of clinical terminology — CBC panels, reference ranges, abbreviations — written for doctors, not for the person whose health they described.

That moment clarified the mission: **healthcare data should belong to the individual**, not disappear across disconnected systems.

## Why Aarogya Vault

The name *Aarogya* (आरोग्य) means **health** in Hindi. It reflects a deliberate choice: this is not a generic global health app adapted for India. It is **India-first healthcare document infrastructure**, designed around how Indian patients actually receive and manage medical records.

Aarogya Vault was founded to solve three specific gaps:

1. **Storage** — One secure vault for all personal health documents
2. **Extraction** — Automatic text extraction from PDFs and images via medical OCR
3. **Understanding** — AI-generated summaries that translate clinical language into readable explanations

The product is built on **Google Cloud and Firebase from day one** — not as a future migration path, but as the production foundation. Authentication, storage, database, serverless compute, AI, and public website hosting all run on Google infrastructure.

## The Bootstrapped Journey

Aarogya Vault is a **bootstrapped MVP**. No external funding. No large team. No accelerator badge — yet.

The build path tells its own story:

| Milestone | What It Proved |
|-----------|----------------|
| `v0.1.0-foundation` | Architecture and project structure |
| `v0.2.0-auth-foundation` | Google Sign-In works end to end |
| `v0.3.0-user-profile` | Firestore user model established |
| OCR frontend architecture | Mobile app ready to consume AI results |
| Gemini OCR pipeline | Cloud Function + Gemini 2.5 Flash integrated |
| `v0.1-google-startups-checkpoint` | Full MVP ready for external review |

Each milestone was earned through code, deployment, and iteration — not pitch decks.

Today the MVP includes:

- A Flutter Android app with authentication, upload, and document management
- A deployed Cloud Function that triggers OCR on every upload
- A live startup website at **aarogyavault.live** with waitlist, legal pages, and transparent MVP status
- A Git-tagged checkpoint representing a production-ready state

The OCR pipeline is technically complete. It is paused only because **Google Cloud credits are exhausted** — a resource constraint, not a technical one. That is precisely why Google for Startups matters: credits convert a working architecture into a running product for real users.

## Vision

> "To become the personal health record layer for the next billion people."

This is not about replacing hospitals or competing with EMR systems. It is about giving every person — starting in India — a secure, understandable archive of their own health story.

The long-term arc:

1. **Document Vault** — Store and understand medical records (MVP — live today)
2. **AI Health Insights** — Patterns and trends across a patient's document history
3. **Family Health Management** — Vaults for parents, children, and dependents
4. **Healthcare Ecosystem Integrations** — Connections with labs, hospitals, and digital health platforms
